European League Parity

Some leagues stay tighter from top to bottom. Others break apart much earlier.

Across seven major European top flights and ten seasons, points-per-game patterns show meaningful differences in how compressed, steep, or stratified league tables tend to be.

This project keeps the lens narrow on purpose: top-flight leagues only, points per game for comparability, and a small set of views that use the existing processed outputs rather than rebuilding the analysis. The point is not to model everything. It is to make the table shape legible.

Method

Method and caveats

The site uses the processed league-table outputs already in the repo and standardizes them with points per game so leagues with different match counts sit on the same scale.

Parity is not a single thing. Some leagues separate at the top, some in the middle, and some more strongly near the bottom. That is why the main line view sits alongside narrower gap comparisons and a ranked summary.

The score shown here is a compact summary, not a definitive truth. It is useful because it stays close to the observed table shape, not because it claims to settle the argument on its own.
